# BGM音源の置き方（神センス0.15チャレンジ）

会場×フェーズごとに音源ファイルを置くと、投影画面(/screen)が自動でその音源を鳴らします。
ファイルが無いフェーズは、内蔵の合成音（プレースホルダ）で自動再生します。

## フォルダ
- bgm/naruto/    … 1部：ボートレース鳴門
- bgm/kojima/    … 2部：ボートレース児島
- bgm/marugame/  … 3部：ボートレース丸亀

## 各フォルダに置くファイル名（mp3推奨。ogg/m4aも可）
| ファイル | 使われる場面 | ループ |
|---|---|---|
| parade.mp3   | 周回展示（エントリー〜予想投票中） | ○（繰り返し） |
| close.mp3    | 投票締切の合図 | × |
| fanfare.mp3  | スタート前のファンファーレ | × |
| race.mp3     | 走行音（大時計カウント〜スタート勝負） | ○ |
| result.mp3   | 結果発表・商品プレゼント演出 | × |

例）bgm/naruto/parade.mp3, bgm/naruto/race.mp3 …

※実際の会場BGM/効果音は各競走場・ボートレース振興会等の権利物です。
　権利のある音源、またはフリー音源（Motion Element等）を配置してください。

## 音源を自動で切り出す（fetch_bgm.sh）
権利のある音源（YouTube等）から必要区間を切り出して自動配置できます。実行は権利保有者が。
1. `fetch_bgm.sh` を開き、`JOBS` に「会場|cue|URL|開始|長さ」を記入（# を外す）
2. `bash fetch_bgm.sh`
3. `bgm/<会場>/<cue>.mp3` が生成される（ラウドネス正規化＋フェード込み）
- 必要: `python3 -m yt_dlp`（導入済）, ffmpeg

## 要点：会場別に集めるのは実質「parade（場内BGM）」だけ
- ファンファーレ(fanfare)は全国共通 → 1音源を3会場に使い回しでOK
- 走行音(race)も共通（未配置なら内蔵の合成エンジン音が鳴る）
- 会場ごとに違うのは周回展示中の場内BGM(parade)
