0. これは何か

6人の挑戦者が「スタート0.15チャレンジ」に挑み、観客が優勝者を予想投票。0秒にいちばん近い（＝神スタート）人が優勝、当てた観客に商品プレゼント。 投影・挑戦者スマホ・観客スマホ・運営の4画面がリアルタイム連動します。

1. 事前準備（開場前）

公開URLを開くだけ：専用サーバは公開URLで常時稼働中。各端末で下表のURLを開きます（インストール不要）。
ネットに繋がっていればOK：会場Wi-Fi・モバイル回線どちらでも可。同じネットワークでなくても連動します（会場外・遠隔からも参加OK）。
4画面を開く（下表）。運営画面のURL欄にも各アドレスが自動表示されます。
音声を有効化：投影画面を1回クリックすると会場BGMの音が解禁＆全cueをプリロード（以降は瞬時に切替）。
BGMファイルを配置済みか確認：bgm/<会場>/parade.mp3（場内BGM・会場別）と bgm/common/<cue>.mp3（fanfare/result/close/race）。未配置のcueは無音（ゲームは動きます）。

導線観客は投影ロビーのQRから /vote に参加。挑戦者URL(/player)は投影に出さず、運営画面からコピーして指定6人へ個別に送る（誤参加防止）。

2. 当日の進行フロー（1ラウンド）

会場を選ぶ：運営ロビーの「1部 鳴門 / 2部 児島 / 3部 丸亀」から今の部を選択 → 投影のBGMがその会場に切替。
挑戦者エントリー：6人が各自スマホ(/player)で号艇を選んで参加。投影ロビーに枠が点灯。周回展示BGMが流れる。
「投票フェーズへ」を押す → 観客が投影QRから /vote で優勝を予想投票。オッズがリアルタイム変動。
「投票締切 → スタート勝負」を押す → 締切音→ファンファーレ→大時計スタート。6人が同時に、大時計が消えたら感覚でPUSH（走行音）。
全員完了で自動的に結果へ（手動なら「結果発表へ」）。0秒に近い順の着順を投影。
「結果・プレゼント発表」 → 優勝者＆商品プレゼント演出。優勝を当てた観客が対象。
「次のラウンド（同メンバー）」で次へ。会場を変える部では、運営ロビーで会場を選び直す。

3. 音（BGM）の流れ

周回展示（会場BGM・ループ） → 締切音 → ファンファーレ（全国共通） → 走行音 → 結果発表、をゲーム進行に合わせて自動で素早く切替。 冒頭の会場選択で 1部 鳴門 / 2部 児島 / 3部 丸亀 の場内BGMが切り替わります。
※ 音源はローカルmp3を事前配置（bgm/ 内）。ネット不要・広告なしで確実に鳴ります。最初の画面クリックで音声解禁。

4. トラブル対応

症状対処
運営画面を誤ってリロードした問題なし。自動で"続きから"復帰します（進行状態はサーバー保存）。
サーバーが落ちた再度 node server.js。前回の進行状態を復元して続行できます。
スマホが「未接続」表示ネット接続を確認（Wi-Fi／モバイル回線）。ブラウザを再読込。URLが合っているか確認。
音が鳴らない投影画面を1回クリック（音声解禁）。🔊ボタンでミュート解除。mp3が bgm/<会場>/parade.mp3 ・ bgm/common/<cue>.mp3 に置いてあるか確認。
挑戦者が参加できない/player URLを個別に再送。既に埋まった号艇は選べません（別の号艇へ）。
やり直したい運営の「最初から」で全リセット。会場選択は保持されます。

5. 注意点

  • 投影に出すのは観客の投票QRだけ。挑戦者URLは個別配布（誤参加防止）。
  • 運営画面(/admin)はゲームの頭脳。開きっぱなしにしてください（閉じても復旧はできますが、開いていること前提）。
  • 公開URL運用：各端末がネットに繋がっていれば、同じWi-Fiでなくても・会場外/遠隔からも同じURLで参加できます。
  • 運営画面(/admin)に 挑戦者・観客のQR があります。挑戦者QRは指定6人だけに見せ、投票QRは観客へ（投影ロビーにも表示）。
